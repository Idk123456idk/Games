# Pong for GitHub Pages

This is a self-contained browser game. No build step or dependencies are required.

## Publish

1. Upload `index.html` and this `README.md` to the **root of the `main` branch** in your GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then save.
5. Wait for the Pages deployment to finish. GitHub will show the game URL in Settings → Pages.

Drag or touch your paddle on the court. On a computer, use the Up and Down arrow keys. The **Neustart** button resets the score.
